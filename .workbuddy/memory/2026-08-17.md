## 桥接层（任务3，已完成）

### 关键结论（踩坑）
1. **yazi 不需要 PTY**：用 `std::process::Command` + 分离管道（stdout piped / stderr null）即可。stdout 是**纯净的事件流**（每行一条），完全没有 ANSI 污染。相比 ConPTY/portable-pty 简单太多。
2. **`--client-id` 和 `ya emit-to` 的 receiver 必须是纯数字**（u64，如时间戳毫秒），不能是字符串。
3. 事件格式：`kind,receiver,sender,{json}`，逗号分隔 4 段；body 是 JSON（如 `cd` → `{"tab":1,"url":"D:\\"}`，`hover` → `{"tab":1,"url":"..."或null}`）。
4. 启动命令：`yazi --client-id <ts> --local-events cd,hover,rename,trash,delete,move,bulk`（cwd 用 current_dir 设置）。发指令：`ya emit-to <client_id> cd <path>`。

### 实现
- `src/yazi.rs`：`YaziClient`（spawn + 事件接收 channel + send 动作）、`YaziEvent` 枚举（Cd/Hover/Other）、解析器。
- `src/main.rs`：Root 视图持有 client/cwd/hovered/log；`cx.spawn` 异步轮询 channel → `weak.update` 更新视图；`nav_button` 测试发 cd 指令。
- `examples/yazi_probe_pipe.rs`：独立探针，验证事件流格式（保留作调试用）。

### GPUI 0.2.2 补充 API 坑
- `.on_click()` / `.overflow_y_scroll()` 是 `StatefulInteractiveElement` trait 方法，只对 `Stateful<Div>` 生效。`div()` 返回 `Div`，需先 `.id(...)` 转成 `Stateful` 再用（Zed 源码同款模式：`.child(...).id(ix).on_click(...)`）。
- 后台更新视图：`cx.spawn(async move |weak, cx| { weak.update(cx, |this, cx| {...}).ok(); }).detach()`。
- **链接报 LNK1104 无法打开 exe**：多半是旧进程还占着 exe 文件，先 kill 再重编。

## 文件列表（任务4+5，已完成）

### yazi Lua 插件发布完整文件列表（关键踩坑）
1. **插件入口是 `main.lua`，不是 `init.lua`**。`init.lua` 是配置根目录的用户初始化文件。
2. **插件不会自动加载**：需在配置根 `init.lua` 里 `require("插件名"):setup()` 才触发插件 `setup`。插件 `main.lua` 返回 `{ setup = function(state, opts) ... end }`。
3. **`YAZI_CONFIG_HOME`** 环境变量可覆盖配置目录 → 把插件放项目 `assets/yazi/` 下，随 GUI 分发，不污染用户全局配置。
4. **`ps.pub(kind, value)` 能被 `--local-events=kind` 捕获**（本地发布即 stdout 事件）。`ps.sub("cd"/"hover", cb)` 订阅内部事件，回调在 sync 上下文可直接访问 `cx`。
5. 文件列表：`cx.active.current.files` 用 `ipairs` 遍历；每个文件 `.name`、`.cha`；cha 字段：`is_dir`/`is_hidden`/`is_link`/`len`(字节大小，**不是 length**)/`mtime`(Unix 秒浮点)/`atime`/`btime`。
6. 调试：`ya.err`/`ya.dbg` 需设 `YAZI_LOG=debug` 才写 `%APPDATA%\yazi\state\yazi.log`。

### 实现
- `assets/yazi/init.lua`：`require("gui-files"):setup()`。
- `assets/yazi/plugins/gui-files.yazi/main.lua`：`ps.sub("cd"/"hover")` → 发布 `gui-files`（cwd + files[{name,is_dir,is_hidden,size,mtime}] + hovered）。
- `src/yazi.rs`：新增 `FileEntry`、`GuiFiles` 事件；spawn 时设 `YAZI_CONFIG_HOME`、`--local-events=cd,hover,gui-files`。
- `src/main.rs`：渲染文件列表（目录蓝色带 `/`、文件带大小、悬停高亮），点目录进入、`上级` 按钮返回父目录。

### GPUI 0.2.2 补充坑
