# 2026-08-17

## yazi GUI 项目启动

### 决策
- 技术栈：**Rust + GPUI 0.2.2**（Zed 编辑器同款 GPU 加速 UI 框架），原生 GUI，跨平台。
- 架构：三层 —— GPUI 前端 / Rust 桥接层 / yazi 引擎（后端进程），通过 yazi DDS 事件流双向通信。
- 关键约束：yazi `--local-events` 只吐增量事件（hover/cd/rename 等），**不吐完整文件列表** → 计划用 yazi Lua 插件 `ps.pub` 发布完整目录。

### 环境搭建（已完成）
- Rust 1.97.1（rustup，stable-x86_64-pc-windows-msvc）+ cargo/clippy/rustfmt
- MSVC Build Tools 14.44.35207 + Windows SDK 10.0.26100.0（cl.exe / link.exe / rc.exe）
- `~/.cargo/bin` 已加入用户 PATH

### 踩坑记录（重要）
1. **rustup 在 Windows 沙箱下硬链接代理失败**：`~/.cargo/bin` 里的 cargo.exe/rustc.exe 等全部变成 0 字节（error 183）。沙箱拦截硬链接创建。解法：PowerShell `New-Item -ItemType HardLink` 手动重建 13 个代理（rustup.exe 的硬链接，靠 argv[0] 判断身份）。`rustup default/update` 在工具链"未变化"时不会重建代理。
2. **GPUI 0.2.2 API 与旧版不同**（crates.io 版 v0.2.x 重构过）：
   - `Render::render(&mut self, window: &mut Window, cx: &mut Context<Self>) -> impl IntoElement`（多了 window 参数，`ViewContext` 改名 `Context`）
   - `WindowOptions` 字段是 `window_bounds: Option<WindowBounds>`（不是 `bounds`），用 `WindowBounds::centered(size, cx)`
   - `TitlebarOptions.title: Option<SharedString>`

### 验证结果
- `cargo build` 成功（703 个依赖全编译，GPUI 0.2.2 本体在 Windows 上编译通过）
- `target/debug/yazi-gui.exe` 运行成功，窗口正常打开（进程存活，无报错）—— **GPUI Windows 支持验证通过**
